# Personal ChatGPT Wrapper

A local web interface for ChatGPT and DALL-E 3 using Streamlit.

## Setup Instructions

1. Extract this ZIP file into a new folder.
2. Open your terminal or command prompt in that folder.
3. Install the required dependencies by running:
   ```bash
   pip install -r requirements.txt
   ```
4. Start the application by running:
   ```bash
   streamlit run app.py
   ```
5. A new tab will open in your browser. Enter your OpenAI API key to start chatting or generating images!
